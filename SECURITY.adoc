= Security Policy

This Eclipse Foundation Project adheres to the https://www.eclipse.org/security/policy/[Eclipse Foundation Vulnerability Reporting Policy].

== How To Report a Vulnerability

If you think you have found a vulnerability in the https://github.com/eclipse-jnosql/jnosql[Eclipse JNoSQL repository], please report it to us through coordinated disclosure.

*Please do not report security vulnerabilities through public issues, discussions, pull requests, mailing lists, or other public channels.*

Instead, report it using one of the following ways:

* Create a https://gitlab.eclipse.org/security/vulnerability-reports/-/work_items/new?issue%5Bconfidential%5D=true[confidential issue] in the Eclipse Foundation Vulnerability Reporting Tracker.
* Report a https://github.com/eclipse-jnosql/jnosql/security/advisories/new[vulnerability] directly via private vulnerability reporting on GitHub.

You can find more information about reporting and disclosure on the https://www.eclipse.org/security/[Eclipse Foundation Security page].

Please include as much of the information listed below as you can to help us better understand and resolve the issue:

* The type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, insecure deserialization, or authentication bypass)
* The affected version(s)
* The impact of the issue, including how an attacker might exploit it
* Step-by-step instructions to reproduce the issue
* The location of the affected source code (tag, branch, commit, or direct URL)
* Full paths of source file(s) related to the issue
* Configuration required to reproduce the issue
* Relevant log output, if available
* Proof-of-concept or exploit code, if available

This information will help us triage your report more quickly.

== Supported Versions

The following Eclipse JNoSQL versions currently receive security updates:

* 1.1.x
* 1.2.x
